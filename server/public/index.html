API Reference

Integrate PrintBridge with SMS, bots, or any HTTP client.

GET/api/printers

List active printers. Includes columns and font_size per printer.

POST/api/messages

Send a message — text, image upload, or image by URL.

🔑 Optional: X-API-Key tags message as API-sourced.
// Text
{ "printer_id": "uuid", "body": "Hello! 👋" }

// Image URL
{ "printer_id": "uuid", "image_url": "https://example.com/photo.jpg" }

// OAuth2 image (Genesys)
{ "printer_id": "uuid",
  "image_url": "https://api-downloads.mypurecloud.com/...",
  "oauth_token_url": "https://login.mypurecloud.com/oauth/token",
  "oauth_client_id": "id", "oauth_client_secret": "secret" }
GET/api/messages/poll

Fetch pending messages (print client).

🔑 Requires X-API-Key.
PATCH/api/messages/:id

Report print result.

🔑 Requires X-API-Key.
{ "status": "printed" }
{ "status": "failed", "error": "Printer offline" }
