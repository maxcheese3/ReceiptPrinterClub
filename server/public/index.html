API Reference

Integrate PrintBridge with SMS gateways, bots, or any HTTP-capable service.

GET/api/printers

List all active printers.

{ "printers": [{ "id": "uuid", "name": "Office Printer", ... }] }
POST/api/messages

Send a message. Supports text, image upload (multipart), or image by URL.

🔑 Optional: X-API-Key header tags message as API-sourced.
// Text only
{ "printer_id": "uuid", "sender_name": "Jane", "body": "Hello!" }

// Image by URL
{ "printer_id": "uuid", "image_url": "https://example.com/photo.jpg" }

// Image via OAuth2 (Genesys etc.)
{
  "printer_id": "uuid",
  "image_url": "https://api-downloads.mypurecloud.com/...",
  "oauth_token_url": "https://login.mypurecloud.com/oauth/token",
  "oauth_client_id": "your-client-id",
  "oauth_client_secret": "your-client-secret"
}
GET/api/messages/poll

Fetch and claim pending messages (used by the print client).

🔑 Requires X-API-Key header.
PATCH/api/messages/:id

Report print result back to the server.

🔑 Requires X-API-Key header.
{ "status": "printed" }
// or: { "status": "failed", "error": "Printer offline" }
EMAILsmtp://yourserver:2525

Send email to <printer-id>@print.local. Body and image attachments are printed.
